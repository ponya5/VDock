1. Developer actions (DL-145)

Nine new keys aimed at people who work with AI coding agents all day. Each one is a normal action you drop on a key; most have a single visible setting.

Agent loop

Agent Prompt

What it doesSends a ready-made prompt (continue, fix the failing tests, explain, commit message...) to the agent session you target. Pick from a dropdown; a custom prompt is tucked under Advanced.
Real useClaude Code stops and asks "what next?" while you are making coffee or on the sofa with your phone. One tap sends "continue" instead of walking back to type it.
Why it mattersMost agent prompts you type are the same five sentences. A key removes the typing and the window switching.
Agent loop

Review Changes

What it doesAsks the agent to review what it just changed, and Mission Control shows a "changes" chip so you see how much was touched.
Real useThe agent finishes a task and edited 14 files. Before accepting, one tap asks it to double-check its own diff.
Why it mattersCatching a bad edit before it is committed is cheaper than reverting afterwards.
Agent loop

Run Tests

What it doesRuns the project's test command and paints the key green or red with the result.
Real useYou glance at your deck from across the desk and see red: tests broke after the last agent change.
Why it mattersStatus you can see without opening a terminal keeps you in flow.
Agent loop

Agent usage / context chip + Compact

What it doesShows how full the agent's context is and how much you have used, plus a Compact button.
Real useA long session starts forgetting things. The chip turns warm at 80%, you hit Compact before quality drops.
Why it mattersRunning out of context mid-task is the most common silent failure of long agent sessions. It also helps you watch your spend.
Dev context

Git Branch

What it doesA live key showing the current branch and whether the tree is dirty.
Real useYou are about to let an agent loose and realise you are still on main.
Why it mattersPrevents the classic "committed to the wrong branch" mistake.
Dev context

Dev Servers

What it doesShows which local dev servers are listening (Vite, Flask, etc.) and lets you act on them from a press menu.
Real use"Port 5173 already in use" - you see what holds it and stop it without hunting through Task Manager.
Why it mattersOrphaned dev servers waste minutes every week.
Dev context

Docker Containers

What it doesShows the running container count/state with a menu to open or restart.
Real useYour database container stopped overnight; the key goes grey before your app errors.
Why it mattersInfrastructure state at a glance, no terminal.
Calls & voice

Mic Mute

What it doesOne key to mute the microphone system-wide, with live red/green state.
Real useMid stand-up, the dog barks: tap mute without finding the call window.
Why it mattersWorks for any call app, not only one vendor.
Calls & voice

Hold-to-talk dictation

What it doesHold the key, speak, release. It triggers Windows voice typing and never presses Enter for you.
Real useDictate a long prompt to the agent instead of typing it, then read it before sending.
Why it mattersSpeaking is faster than typing for long instructions; never auto-submitting avoids sending a mis-heard command.
Mission Control

Prompt presets + changes chip

What it doesThe existing Mission Control window now offers the same prompt presets and shows the changes chip, so you do not need extra keys.
Real useSeveral agents running; you answer each from one screen.
Why it mattersReuses a surface you already have rather than adding clutter.

2. Agent alerts you can recognise

When an agent needs you, the popup now looks like that agent.

Alerts

Branded popups, glow and dock chips

What it doesClaude Code shows its logo with the orange theme; Cursor, Antigravity and Codex each get their own logo and colour. The waiting dock and screen-edge glow follow the same colours.
Real useThree agents are running. Orange means Claude wants you, silver means Cursor - you know who before reading.
Why it mattersYou triage by colour in under a second.
Alerts

Remove an agent hook

What it doesSettings, Agents & automation, Agent hooks has a Remove hook button (with an inline Yes / Cancel) for each hooked agent. It deletes only VDock's own entries and leaves your other hooks untouched.
Real useYou stop using Codex on this PC and want VDock out of its config.
Why it mattersInstalling is no longer a one-way door.
Alerts

Auto scene switching + clearer trigger wording

What it doesThe deck switches scenes by the app you are in, with rewritten, plainer trigger labels.
Real useOpen Spotify and the media scene appears by itself.
Why it mattersThe right keys are already in front of you.

3. Phone and tablet as the touch screen (DL-147)

Most people do not own a spare touch panel, but everyone has a phone or tablet. VDock now treats them as first-class decks.

Foundation

One device model: phone / tablet / panel / desktop

What it doesA single place decides which layout and touch size to use, with a per-device touch scale (phones 1.0, tablets 1.5).
Real useThe same profile looks right on your 7" panel, your phone and your iPad.
Why it mattersScattered width checks caused a blank deck on 768px tablets and your desktop shared the tablet's 2x size. Both are fixed.
Phone

Portrait deck and approval remote

What it doesPortrait phones fold the deck into 3 columns (no more "rotate to landscape" wall). The phone menu has Mission Control with a count of agents that need you; Approve/Deny give a short vibration.
Real useYou are in the kitchen, a permission prompt appears, you approve it from your phone.
Why it mattersThis is the highest-value mobile use: unblocking an agent from anywhere in the room.
Tablet

Tablet layouts and edit mode

What it doesChecked on iPad mini, 10th gen, Air/Pro 11", Pro 12.9", Galaxy Tab and Fire HD 10, portrait and landscape. Edit mode uses a drawer (bottom sheet in portrait) so keys stay large. Windows narrower than 600px use the phone layout.
Real useAn old iPad on a stand becomes your deck.
Why it mattersTablets are the most common "free" touch screen.
Connection

Reconnect banner and live profile sync

What it doesIf the phone sleeps or Wi-Fi drops, a banner explains it and the deck resumes when you return. Profile changes made on the PC reach open phones within about half a second.
Real useYou edit a key on the PC and your tablet updates without a refresh.
Why it mattersPhones sleep constantly; silent dead decks looked broken.
Pairing

QR pairing, install guidance and optional HTTPS

What it doesScan the QR on the Connect page; with a deck password set, the QR carries a single-use token that expires in 10 minutes. An "Add to Home Screen" guide and a keep-screen-on toggle are included. HTTPS (USE_SSL) is off by default.
Real usePair a new phone in seconds without typing an address or password.
Why it mattersFirst-time setup is where most people give up. HTTPS is needed for true app install and the wake lock.
Fixes

Touch bugs

What it doesHold keys keep working when a finger drifts; a long press no longer opens the button editor; a failed server connection no longer creates a stray profile.
Why it mattersThese made the phone feel unreliable.

4. Settings you can find things in (DL-146)

Settings

Overview, five sections, search and deep links

What it doesSettings opens on Overview with "Needs attention" rows and quick switches. Sections: Appearance, Agents & automation, Integrations, Devices & network, System. Search jumps to the right page; old links still work.
Real useType "token" and land on where to add your GitHub token.
Why it mattersSettings had grown into one 5,500-line page that was hard to navigate.
Settings

Accounts & keys

What it doesShows which integrations have a key set (status chips) and lets you save, replace or remove a key right there (masked input, this PC only, active immediately). Copy-line and Open .env remain under Advanced. A saved key is never shown again.
Why it mattersKeys are still stored in .env, but you can see what is missing and fix it without leaving the app.
Settings

Deck password next to the network switch

What it doesTurning on phone access prompts for a password right there.
Why it mattersAnyone on your Wi-Fi could previously control your PC if you forgot to set one.

5. Production readiness

Safer setup

Startup validator that names missing settings (never their values), atomic file writes so a crash cannot corrupt config, a secret key generated automatically, .env.example files for backend and frontend, one version source (2.3.0), a health endpoint with uptime.

Repo hygiene

Build and scratch folders untracked and ignored, Docker and old deploy scripts removed, .gitattributes and .editorconfig added, a test that fails if anything touches your real .env.

Automation and security

CI with read-only permissions, Windows and audit jobs, scripts/check.ps1 to run everything locally, Electron updated to clear high-severity audit findings, SECURITY.md network guidance.

README

Refreshed (under 300 lines) with screenshots of the new features.
